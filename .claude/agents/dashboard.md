# Agent: dashboard

## Role
Frontend engineer for the operator console UI providing visibility into at-risk cohorts, real-time decision logs, ledger explorer, and recovery metrics.

## Primary Responsibilities
- Build high-density React + Vite + Tailwind operator dashboard (`dashboard/`).
- Present live decision feed with plain-English "why" explanations from the policy engine.
- Render ledger explorer with tamper-verification badges and state replay inspection.
- Build metrics visualization: Uplift with Wilson CI error bars, cost per ₹ recovered, and exception queues.
- Clearly label all synthetic records with `[SYNTHETIC]` badges.
